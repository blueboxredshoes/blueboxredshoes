see you next year is an annual digital countdown to ring in the new year. as jan 1st strikes 00:00:00, an ASCII firework display is set off. this was hand created frame-by-frame. there is accompanying music (actually made on my nintendo 3ds!) the display is programmed to run for exactly one hour, so must be caught quickly. it is designed to be viewed together, whether physically or across digital space. whilst having limited interaction and, really, limited purpose, I wanted to make something that existed purely for the sake of fun -- because the internet should be fun.
